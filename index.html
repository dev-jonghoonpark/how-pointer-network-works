Pointer Networks — 어텐션으로 입력을 가리키기

점 10개의 볼록 껍질을 구하라고 하면 답은 “2번, 4번, 3번, 5번…” 같은 입력의 번호입니다. 그런데 seq2seq의 출력층은 칸 수가 학습할 때 정해져서, 점이 11개가 되면 “11번”이라고 말할 칸이 없습니다. Pointer Network(Vinyals·Fortunato·Jaitly, NeurIPS 2015)는 이 문제를 어텐션 한 줄을 바꿔서 풉니다. 어텐션 가중치로 인코더 상태를 섞지 않고, 그 가중치 분포를 그대로 출력으로 쓰는 것입니다.

1. 출력할 칸이 미리 정해져 있다

seq2seq 디코더는 스텝마다 출력층 \(W_o\)로 점수를 만들고 softmax를 씌웁니다. 번역이라면 출력 사전은 단어 3만~5만 개쯤이고, 학습이 끝나면 바뀌지 않습니다.

$$p(C_i\mid C_1,\dots,C_{i-1},\mathcal P)=\operatorname{softmax}(W_o\,d_i),\qquad W_o\in\mathbb R^{K\times h}$$ K는 출력 사전의 크기입니다. 행렬 모양에 박혀 있어서 모델을 다시 만들지 않으면 바꿀 수 없습니다.

볼록 껍질 문제로 seq2seq를 학습시키면 출력 사전은 “1번 점”부터 “n번 점”까지에 시작·끝 기호가 붙은 것이 됩니다. 논문도 이 점을 짚습니다. 출력 사전 크기가 n으로 고정되니 n마다 모델을 따로 학습해야 한다는 것입니다. 아래에서 점 개수를 바꿔 보세요. 왼쪽 모델은 점 5개로 학습한 seq2seq입니다.

데모 1 · 점이 6개가 되면 seq2seq는 ‘6번’을 말할 수 없다

초록 선이 볼록 껍질입니다. 정답 순서는 논문처럼 껍질 위에서 번호가 가장 작은 점부터 반시계 방향으로 적습니다.

정답 출력 순서

seq2seq (n = 5로 학습) — 출력층의 칸

Ptr-Net — 출력 칸 = 지금 들어온 입력

seq2seq가 낼 수 없는 정답 토큰0
Ptr-Net 출력 분포의 칸 수8

점이 3~5개일 때도 seq2seq가 멀쩡한 것은 아닙니다. 칸이 남을 뿐, 학습 때와 길이가 다르면 인코더가 보던 입력 분포가 달라집니다. 점이 6개를 넘으면 답에 6 이상의 번호가 들어가는 순간 그 토큰은 아예 낼 수 없습니다. 빨간 점선 칸이 그런 토큰입니다.

2. 정답이 ‘입력의 번호’인 문제들

논문은 평면 위의 점 집합 \(\mathcal P=\{P_1,\dots,P_n\}\)을 받아 번호열 \(\mathcal C^{\mathcal P}=\{C_1,\dots,C_{m(\mathcal P)}\}\)을 내는 문제 세 개를 풉니다. 점은 모두 \([0,1]\times[0,1]\)에서 고르게 뽑았습니다.

  • 볼록 껍질 — 모든 점을 감싸는 가장 작은 볼록 다각형의 꼭짓점. 정확한 알고리즘은 \(O(n\log n)\)입니다.
  • 들로네 삼각분할 — 어떤 삼각형의 외접원 안에도 다른 점이 없는 삼각분할. 출력은 번호 세 개짜리 묶음의 나열입니다. 예: \(\{\Rightarrow,(1,2,4),(1,4,5),(1,3,5),(1,2,3),\Leftarrow\}\)
  • 외판원 문제(TSP) — 모든 도시를 한 번씩 들르고 돌아오는 가장 짧은 경로. NP-hard입니다. 학습용 정답은 \(O(2^n n^2)\)인 Held-Karp 동적 계획법으로 n = 20까지 만들었습니다.

셋 다 출력에 새로운 값이 하나도 없습니다. 답은 늘 입력 중 무엇을 어떤 순서로 고르느냐입니다. 아래 데모는 같은 점 집합에 볼록 껍질과 TSP를 실제로 풀어서 출력 번호열을 보여 줍니다. TSP 최적해는 논문처럼 Held-Karp로 구합니다.

데모 2 · 같은 입력, 다른 번호열

빈 곳을 누르면 점이 추가되고(최대 12개), 점을 끌면 옮겨집니다. 출력 번호열은 점을 움직일 때마다 다시 계산됩니다.

출력 번호열

출력을 한 줄로 쓰는 방법이 여러 가지면 학습이 흔들립니다. 그래서 논문은 표기를 하나로 정했습니다. 볼록 껍질은 “번호가 가장 작은 점부터 반시계 방향”, TSP는 “항상 1번 도시에서 출발”, 들로네는 “삼각형을 내심 좌표의 사전순으로, 각 삼각형 안의 번호는 오름차순으로” 적습니다. 들로네 쪽은 이렇게 순서를 정하지 않았을 때 결과가 나빴다고 적혀 있습니다.

3. 어텐션을 섞지 말고 가리키게

저자들은 처음에 볼록 껍질을 평범한 LSTM seq2seq로 풀었습니다. 그러자 껍질 위의 점이 입력 뒤쪽에 늦게 나올수록 정확도가 떨어졌습니다. 그래서 디코더가 입력 전체를 언제든 볼 수 있게 Bahdanau 어텐션을 붙였고, 성능이 크게 올랐습니다. 이때 어텐션이 어디를 보는지 들여다봤더니 입력 쪽의 정답 점을 ‘가리키고’ 있었다고 합니다. Ptr-Net은 여기서 나왔습니다.

인코더 상태를 \(e_1,\dots,e_n\), 디코더 상태를 \(d_i\)라고 할 때, 논문 식 (3)의 어텐션은 이렇습니다.

$$u^i_j=v^\top\tanh(W_1e_j+W_2d_i),\qquad a^i_j=\operatorname{softmax}(u^i)_j,\qquad d'_i=\sum_{j=1}^n a^i_j\,e_j$$ 어텐션: 점수 → 분포 → 가중 평균 \(d'_i\). \(d'_i\)를 \(d_i\)에 이어 붙여 고정 크기 출력층으로 예측합니다.

Ptr-Net은 마지막 단계를 지웁니다.

$$u^i_j=v^\top\tanh(W_1e_j+W_2d_i),\qquad p(C_i\mid C_1,\dots,C_{i-1},\mathcal P)=\operatorname{softmax}(u^i)$$ Ptr-Net: 점수 → 분포 → 끝. 분포의 길이가 n이므로 출력 사전도 저절로 n칸이 됩니다. 다음 스텝 디코더 입력으로는 방금 고른 점의 좌표 \(P_{C_{i-1}}\)를 그대로 넣습니다.

파라미터 \(v, W_1, W_2\)의 크기는 은닉 차원만으로 정해지고 n과 상관이 없습니다. 같은 가중치가 점 5개에도, 500개에도 그대로 쓰입니다. 끝 기호 \(\Leftarrow\)는 논문 그림 1(b)처럼 인코더 맨 앞에 특별한 자리를 하나 두고, 끝내고 싶을 때 그 자리를 가리키게 해서 처리합니다.

데모 3 · 섞으면 입력 사이 어딘가, 가리키면 입력 중 하나

2차원 인코더 상태 e₁~e₅와 디코더 상태 d(파란 화살표)입니다. 화살표 끝을 끌어 보세요. 그림을 단순하게 하려고 점수는 내적 \(u_j=e_j\cdot d\)로 계산합니다(논문은 위의 덧셈형 점수를 씁니다). d가 길수록 분포가 뾰족해집니다.

어텐션 출력 d′—
포인터 출력—

핵심

어텐션의 결과 d′는 e들의 볼록 결합이라 늘 e들이 만드는 다각형 안쪽에 있고, 분포가 아주 뾰족하지 않으면 어느 입력과도 같지 않습니다. 포인터는 그 분포에서 칸 하나를 고를 뿐이라 결과가 반드시 입력 중 하나입니다. 논문은 좌표를 직접 회귀하게 하는 방법도 언급하면서, 그러면 출력이 입력에 정확히 대응한다는 보장이 없어 긴 시퀀스에서 예측이 흐려진다고 지적합니다.

4. 브라우저에서 학습하는 미니 Ptr-Net

이제 진짜로 학습시켜 봅니다. 과제는 숫자 정렬입니다. 0~1 사이 숫자 n개를 받아 작은 것부터 차례로 가리키면 됩니다. 논문 결론에서 다음 과제로 꼽은 것이 정렬이기도 합니다.

브라우저에서 몇 초 안에 돌리려고 LSTM은 빼고 포인터 부분만 남겼습니다.

$$u^i_j=v^\top\tanh\big(\underbrace{A\,x_j+a_0}_{W_1e_j}+\underbrace{B\,x_{C_{i-1}}+b_0}_{W_2d_i}\big),\qquad p(C_i)=\operatorname{softmax}(u^i)$$ 은닉 차원 16. 인코더는 숫자 하나를 16차원으로 펴는 선형 변환이고, 디코더 상태는 “직전에 가리킨 숫자”만 봅니다(첫 스텝에는 학습되는 시작 벡터 s). 파라미터는 A·a₀·B·b₀·s·v 각 16개, 모두 96개입니다. 학습은 n = 5~10짜리 무작위 수열, 교사 강요(teacher forcing), 교차 엔트로피, Adam(학습률 0.01, 배치 32)으로 합니다.

논문 모델의 디코더는 LSTM이라 지금까지 무엇을 골랐는지 기억합니다. 이 미니 모델은 직전 하나만 보므로, “이미 고른 위치는 다시 고르지 않는다”는 규칙을 마스크로 줄지 말지가 중요해집니다. 마스크를 켜면 이미 가리킨 위치의 점수를 \(-\infty\)로 만들어 softmax에서 뺍니다.

데모 4 · 정렬을 배우는 포인터

5. 같은 가중치로 더 긴 입력 — 그리고 마스크

데모 4의 모델은 길이 5~10 수열만 봤습니다. 그런데 파라미터 96개 중 어느 것도 n에 묶여 있지 않으니, 길이 50짜리 수열에도 그대로 돌릴 수 있습니다. seq2seq라면 출력층이 맞지 않아 실행조차 안 되는 상황입니다. 아래 버튼은 지금 모델을 길이마다 수열 150개로 시험합니다.

데모 5 · 길이별 정답률과 ‘유효하지 않은 출력’

파랑 = 수열 전체를 맞힌 비율, 초록 = 위치별로 맞힌 비율, 빨강 점선 = 같은 위치를 두 번 이상 가리켜 순열이 아니게 된 비율. 회색 띠가 학습 때 본 길이입니다. 다시 평가하면 직전 결과가 옅은 선으로 남습니다.

수열 정답률 위치별 정답률 유효하지 않은 출력

데모 4에서 모델을 학습시킨 뒤 눌러 보세요.

권장 실험 순서는 이렇습니다.

  1. 마스크를 켠 채 학습하고 평가합니다. 길이 50에서도 거의 다 맞힙니다. 마스크가 이미 고른 숫자를 지워 주므로, 모델은 매 스텝 “남은 것 중 가장 작은 수”만 찾으면 됩니다. 이 규칙에는 n이 들어 있지 않습니다.
  2. 마스크를 끄고 가중치를 초기화한 뒤 다시 학습하고 평가합니다. 이번에는 “직전 숫자보다 크면서 가장 가까운 수”를 스스로 배워야 합니다. 학습 길이에서도 정답률이 떨어지고, 길이가 길어질수록 같은 숫자를 또 가리키는 출력이 급격히 늘어납니다. 숫자 사이 간격이 약 1/n로 좁아져 구분이 어려워지기 때문입니다.
논문에서도 같은 일이 있었습니다. TSP에서는 빔 서치가 유효한 경로만 고려하도록 제한했는데, 그러지 않으면 모델이 도시를 두 번 들르거나 빼먹었고 n > 20에서는 10% 이상의 경우에 유효한 경로를 하나도 내지 못했다고 합니다. 반면 볼록 껍질과 들로네 실험에서는 디코더를 제한하지 않았습니다. 포인터는 “입력 중 하나”만 보장할 뿐 “각 입력을 한 번씩”까지 보장하지는 않습니다.

6. 논문 실험 결과

모든 실험에서 은닉 유닛 256개 또는 512개짜리 단층 LSTM을 썼고, 학습률 1.0의 SGD, 배치 128, 가중치 초기화 범위 −0.08~0.08, 기울기 L2 클리핑 2.0, 학습 쌍 100만 개였습니다. 저자들은 하이퍼파라미터 탐색을 거의 하지 않고 세 문제에 같은 설정을 썼다고 밝힙니다.

A1·A2는 \(O(n^2)\) 근사 알고리즘, A3는 최적의 1.5배 이내를 보장하는 \(O(n^3)\) Christofides 알고리즘입니다. 눈여겨볼 줄이 둘 있습니다.

  • A1 데이터로 학습한 n = 50: 가장 나쁜 근사 알고리즘 A1의 출력을 정답 삼아 배웠는데, 결과 경로(6.42)가 A1 자신(6.46)보다 짧습니다. 흉내 내던 알고리즘을 넘어선 것입니다.
  • 5–20으로 학습해 더 긴 n에 적용: 25에서는 거의 완벽하고 30도 괜찮지만, 40부터 무너집니다(50에서 7.66). 볼록 껍질이 학습 길이의 10배까지 버틴 것과 대조적인데, 저자들은 TSP를 푸는 알고리즘이 \(O(n\log n)\)보다 훨씬 복잡하기 때문일 수 있다고 봅니다.

7. 그다음: 복사하는 포인터

“입력을 가리킨다”는 발상은 기하 문제 밖에서 더 오래 쓰였습니다. 요약·질의응답·대화에서 자주 문제가 되는 것은 사전에 없는 단어(OOV)입니다. 사람 이름이나 지명은 원문에 있는데 출력 사전에는 없어서 [UNK]로 나옵니다. 포인터를 쓰면 원문 위치를 가리켜 그 단어를 복사할 수 있습니다.

대표적인 형태가 See·Liu·Manning(ACL 2017)의 pointer-generator입니다. 디코더가 스텝마다 “생성할 확률” \(p_{\text{gen}}\)을 내고, 사전에서 생성하는 분포와 어텐션으로 복사하는 분포를 섞습니다.

$$P(w)=p_{\text{gen}}\,P_{\text{vocab}}(w)+(1-p_{\text{gen}})\sum_{i:\,w_i=w}a_i$$ 두 번째 항이 Ptr-Net의 포인터입니다. 원문에 같은 단어가 여러 번 나오면 그 위치들의 어텐션이 더해집니다. 사전에 없는 단어는 \(P_{\text{vocab}}(w)=0\)이라 복사로만 나올 수 있습니다.

데모 6 · 생성할까, 복사할까

요약문의 첫 단어를 고르는 스텝입니다. 원문 “Okonkwo won the Valencia marathon on Sunday”에서 Okonkwo와 Valencia(★)는 사전에 없습니다. 최종 분포의 주황은 원문에서만, 파랑은 사전에서만, 보라는 양쪽에서 확률을 받은 단어입니다. 어텐션과 사전 분포 숫자는 설명을 위해 정한 예시 값입니다.

같은 계열의 연구를 몇 가지 더 꼽으면 이렇습니다.

  • CopyNet (Gu 외, ACL 2016) — 생성 모드와 복사 모드의 점수를 한 softmax 안에서 함께 정규화합니다.
  • Pointer Sentinel (Merity 외, 2016) — 언어 모델에서 최근 문맥의 단어를 가리키는 포인터와 일반 softmax를 섞습니다.
  • Order Matters (Vinyals·Bengio·Kudlur, ICLR 2016) — 같은 저자가 숫자 정렬 같은 집합 입력 문제에서 입력·출력 순서가 학습에 미치는 영향을 다룹니다.
  • Neural Combinatorial Optimization with RL (Bello 외, 2016) — Ptr-Net을 지도 학습 대신 강화 학습(경로 길이를 보상으로)으로 학습해, 최적해 정답 없이 TSP를 풉니다.
  • Attention, Learn to Solve Routing Problems! (Kool 외, ICLR 2019) — 인코더를 Transformer로 바꾸고 디코더는 여전히 입력 노드를 가리키는 구조로 경로 문제를 풉니다.
